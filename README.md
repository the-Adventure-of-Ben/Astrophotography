# Astrophotography
----currenlty in development----
Very specilised to my need currently so that I can test the software with the hardware, though it will be a generalised so that others can use it more easily.

This is a project that should allow for full control of a telescope that doesn't have an automatic tracker as they are expensive. the system is split into two main parts telescope control and camera control.
Current Telescope control system:
. Two stepper motors (one for azimuth, other for altitude) no slewing
. arduino to control the stepper motors
.
